# website-automation social media assets

Public media for scheduled website-automation posts. Metricool pulls files from this branch by URL.
`main` of this repo is unrelated and untouched.

- `posts/<date>-<slug>/`: final media and caption of each post
- `tools/`: slide and reel renderer (`make_industry.py` builds one post for a queued industry)
- `data/industry_queue.json`: industries for the weekly posts
- `batches/`: the hand-built first two weeks
